# タスク管理アプリ

## 概要

Flaskを用いて、ログイン機能付きのタスク管理アプリを開発しました。
ユーザーごとにデータを分離し、ログイン状態をセッションで管理しています。

---

## 使用技術

* Python
* Flask
* SQLite
* Bootstrap

---

## 機能

* タスクの追加
* タスクの編集
* タスクの削除
* タスク一覧表示
* ログイン機能
*ユーザーごとのデータ管理

## 工夫した点

* SQLiteを使用し、データの永続化を実現
* POST後にリダイレクトを行うことで二重送信を防止（PRGパターン）
* Bootstrapを使用してUIを改善し、視認性と操作性を向上

---

## 起動方法

pip install -r requirements.txt
python app.py

## 初期設定

初回起動時にデータベース（SQLite）が自動作成されます。
